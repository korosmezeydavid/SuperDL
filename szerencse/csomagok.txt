# A Szerencsesüti modul 6 óránként letölti ezt a fájlt. Ha van benne csomag,
# akkor mindenkinél AZ megy (a felhasználó nem kapcsolhatja ki); ha nincs,
# a rendes sütik jönnek. Csomagot Dávid szólására teszünk be és veszünk ki.
# Kész csomagok: szerencse/csomag_tar.txt – onnan kell ide átmásolni.
#
# Egy csomag a „@nev:" sorral kezdődik.
#   @mod         csere = csak a csomag sütijei jönnek (ez az alap);
#                hozzaad = a rendes sütik közé keveredik (@arany: 0–100 %)
#   @udvozles    ezt mondja az első kibontáskor
#   @tol / @ig   (nem kötelező) hónap-nap vagy teljes dátum, ha magától
#                járjon le
# Utána [bolcsesseg] [vicc] [beszolas] [buntetes] [bonusz], mint az
# uzenetek.txt-ben. Büntetés: „1:", „2:", „10:" vagy „24:" a sor elején.
# Hang a sor végén: |nagy_nevetes |kuncogas |huncut |punch
