  1. PROJEKT RÖVID LEÍRÁS
================================================================================

  A Super DL egy magyar nyelvű Android launcher vak és gyengénlátó
  felhasználóknak. Gesztusokkal (fel/le/jobbra/balra swipe) és hanggal
  (TTS + diktálás) vezérelhető. Nem webes felület — natív Android app.

  Fő technológiák:
    - Kotlin, Android SDK 34, minSdk 26
    - Gradle build (gradlew.bat assembleRelease / assembleDebug)
    - TTS, SpeechRecognizer, CameraX, ML Kit, saját bankjegy-modell
    - Elena hangos asszisztens (korábban „Hangos asszisztens")

  ADB útvonal:
    C:\Users\msn\AppData\Local\Android\Sdk\platform-tools\adb.exe

  BUILD IDŐ / MCP TIMEOUT (fontos Claude/AI számára):
    A teljes release build ~6 perc, ami TÚLLÉPI az MCP hívás időkorlátját.
    A start_process ilyenkor timeout hibát ad, DE A BUILD TOVÁBB FUT.
    Teendő: list_sessions -> read_process_output a PID-del, ne indíts újat.
    Tipp: a kimenetet fájlba irányítsd (*> build_log.txt), mert a
    "| Select-Object -Last 40" a pipeline végéig pufferel, így közben
    nem látszik semmi.

  ISMERT BUILD BUKTATÓ — R8 / ProGuard:
    Release buildnél az R8 elhasal a hiányzó opcionális osztályokon.
    A megoldás mindig ugyanaz: az R8 maga legenerálja a szükséges sorokat ide:
      app\build\outputs\mapping\release\missing_rules.txt
    Ezeket kell bemásolni az app\proguard-rules.pro végére (-dontwarn).
    Eddig így kezelt esetek: PDFBox JPEG2000, BouncyCastle LDAP,
    Tink KeysDownloader (Google HTTP kliens).
